# 公式索引からの記事カタログ収集

対象はアプリ対応の17掲載サイト。インドネシア語とアートワーク・著者ページ・ガイド・コンテスト一覧は除外する。

`catalog-index-sources.json` に到達確認済みの公式索引を登録。`catalog-indexes.js <lang>` はシリーズ、表、リスト、div/br、Taleカード、支部別セクション、ページ送り、同一サイトの一覧用HTML埋め込みを読む。Taleの著者順・題名順・作成日順索引も追跡し、GoIやカノン等の索引に載る公開ハブは作品一覧として次の巡回へ追加する。通常の記事本文からの参照リンクだけでは収録範囲を広げない。

## 週次Actions

1. 既存の言語別通常記事クロールを実行する。
2. 同じ言語の公式索引を収集。通常記事の取得済み本文情報を再利用し、同じSCPを二重取得しない。1言語600リクエスト・5分を上限とし、取得待ちを次回へ引き継ぐ。
3. 既存artifactのpartial-dataに索引スナップショット・記事メタデータを同梱する。
4. `merge-catalog-indexes.js` で追加カタログを生成する。従来の1リンク条件による生成は週次処理から外した。
5. 未作成・空本文を旧JSONとmobile-v1/v2の入力から除外する。追加記事は従来通りmobile-v2へ統合する。
6. 既存mobile-catalog.jsが記事gzipを生成・検証し、最後に配信データをcommitする。本番リポジトリは今回変更しない。

## 未作成ページ

- 一覧のnewpageは未作成枠として除外する。未翻訳枠を英語版URLで埋める従来の動作は行わない。
- 詳細取得の404/410、明示的な未作成案内、本文が空のページは収録しない。短文・画像・音声・動画・埋め込みを持つ作品は単純な文字数で除外しない。
- 403/429/5xx、TLS、タイムアウト、未知のHTML構造は未作成と断定しない。既存の正常な記事と前回の索引スナップショットを維持し、失敗と取得待ちを記録する。
- 索引の掲載数が突然半減した場合も、パーサーの不具合による大量削除を避ける。明示的な未作成リンク情報は維持する。

## 記事IDとデータ形式

従来から存在する記事IDを優先し、SCPは原作支部とSCP種別に対応する既存IDと照合する。新しい提案・バリアントはスラッグを保持して別作品IDにする。一般文書は既存のdocument-IDを維持する。複数索引から同じ作品が見つかっても重複登録しない。索引URL・セクションは収録と原作支部分類の根拠として保持する。

通常記事の評価・クラス・画像の抽出関数を追加記事でも再利用し、mobile-v2の既存フィールドに保存する。アプリのDBスキーマや起動時配信パスは変更しない。

## 再開と進捗

`local-data/catalog-indexes/<lang>.json.gz` が週次で引き継ぐ入力。作業中は `partial-data/catalog-indexes/` に保存する。書き込みはディスクへのflush後にrenameし、正常な前回版を.bakへ保持する。壊れた作業版は隔離し、バックアップか配信済み版から再開する。

ローカル初回収集は `node tool/run-index-bootstrap.js`。既存の週次エントリポイントを言語ごとに呼び、進捗は `relations/index-bootstrap/progress.json` / `progress.md` と言語別ログに保存する。この補助プロセスはcommitやpush、通知送信を行わない。取得待ちがなくなるか、その時点で再試行可能な対象がなくなった時点で終了する。

言語全体の取得結果がない場合は直前の追加カタログを維持する。言語の索引を取得できた場合は、その索引への掲載を収録条件とし、旧1リンク条件だけの記事は残さない。取得済み索引に載る既存記事は、本文の再確認待ちでも従来の記事IDで維持する。個別索引の取得失敗は前回の索引スナップショットを維持する。収集の進捗とアプリへの配信状態は別であり、再生成・検証・push完了前のデータを配信済みとは扱わない。

## 検証

Node全体101件成功。未作成・空本文・画像だけの作品・一時障害・新しいTaleカード・ページ送り・既存ID・gzip配信・壊れたチェックポイントの復旧を検証した。新しい除外条件で翻訳済み扱いから外れた45件は実際に本文を再確認し、すべて利用不能だった。

ローカルで配信gzipを何度も生成した場合は、push前に `node tool/retain-published-payloads.js` を実行し、公開済みmanifestが参照する旧ファイルを保持する。
